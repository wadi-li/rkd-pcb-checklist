ЕСКД: чек-лист РКД — печатная плата (деталь) и печатный узел (сборочная единица) v1.5

Схема Э3 (.dchxml) и плата DipTrace (.dipxml) → состав РКД по ГОСТ Р 2.102-2023, ГОСТ 2.123-93, ГОСТ 2.417-91 → отчёт

1Исходные данные DipTrace

Файлы читаются только в браузере и никуда не передаются. В DipTrace: Файл → Сохранить как → формат XML (.dchxml / .dipxml).

2Изделие и основная надписьподсвечены поля, взятые из файлов

Обозначения — по ГОСТ Р 2.201-2023. Основной КД рекомендуется обозначать без кода вида документа (ГОСТ Р 2.102-2023, п. 5.5). Код класса платы проверьте по классификатору ЕСКД.

3Анализ схемы и платы

Загрузите схему и плату — здесь появятся параметры для чертежей, спецификации и производства, сверка схемы с платой и замечания.

4Чек-лист РКД

основной основной КД (ГОСТ Р 2.102-2023, пп. 5.3–5.4) нужен требуется для изготовления (ТЗ, ГОСТ 2.123-93, практика) о необязательный — по решению разработчика или ТЗ авто проверено по файлам DipTrace

7Структура папок проекта

Один уровень — два пробела. Метки #… указывают, куда записываются документы: #asm-tb — ТБ узла, #asm-tb.csv — её CSV, #src — исходники, #root — корень. Папки без меток можно добавлять, переименовывать и удалять.
