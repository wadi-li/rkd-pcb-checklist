# Локальный шрифт ГОСТ

Положите сюда `GOST_B.ttf` (шрифт ГОСТ тип Б) и выполните `python build.py` — будет собран
`dist/rkd_pcb_checklist_v<версия>_gost.html` со встроенным шрифтом.

Шрифт «GOST type B» принадлежит АО «АСКОН» и в репозиторий не добавляется (см. `.gitignore`).
Собранный с ним файл предназначен только для личного использования.
